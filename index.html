Hướng dẫn lấy Gemini API Key
  1. Nhấn Mở Google AI Studio bên dưới và đăng nhập tài khoản Google.
  2. Vào mục API Keys, chọn Create API key (nếu chưa có).
  3. Sao chép khóa của bạn và dán vào ô API Key ở đây.
Mở Google AI Studio ↗
  1. Nhấn Mở OpenAI API Keys và đăng nhập tài khoản OpenAI.
  2. Chọn dự án, nhấn Create new secret key để tạo khóa.
  3. Sao chép khóa và dán vào ô API Key. API OpenAI có thể yêu cầu thiết lập thanh toán riêng với ChatGPT.
